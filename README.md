# 🍜 华科觅食地图 (HUST Food Map)

这是一个基于 **Node.js + Leaflet + Turso (云端 SQLite)** 的全端觅食推荐与评分系统。支持地图交互、智能推荐、大众打分与标签，以及完善的后台管理功能。

---

## 📁 一、项目目录结构与文件职责

```text
lindaCoca-map-main/
│
├── index.html          # 【前端页面】整个网站的 HTML 骨架、CSS 样式、所有页面的布局
├── app.js              # 【前端逻辑】核心代码！包含地图渲染、筛选推荐、评分交互、管理员弹窗等
│
├── package.json        # 项目依赖配置（包含我们需要的 @libsql/client 和 dotenv）
├── .env                # ⚠️ 环境变量（需自己创建，不上传GitHub）。存放云数据库地址和密钥
│
├── server/             # 【后端服务】
│   ├── server.mjs      # 后端启动入口（监听 3000 端口，连接数据库）
│   └── app.mjs         # 后端接口路由（处理前端的增删改查、登录验证、打分接口）
│
└── database/           # 【数据库与初始数据】
    ├── init.mjs        # 数据库初始化脚本（建表、如果表空了就导入 seed 数据、修复脏数据）
    ├── schema.sql      # 数据库表结构定义（表字段、约束等）
    ├── seed.json       # 初始地点和菜品数据（前端如果没有连后端，会降级读取这个文件）
    └── ratings.json    # 项目组整理的初始菜名基础评分，建库时会自动注入
```

## 💻 二、如何在本地跑起来？

### 1. 环境准备
- 电脑安装 **Node.js** (建议 v20 或以上版本)。
- VSCode 终端。

### 2. 配置环境变量 (`.env`)
在项目**根目录**新建一个 `.env` 文件，填入以下内容（向负责人要云数据库的密钥）：
```env
# 如果你用的是 Turso 云数据库，填入如下：
TURSO_DATABASE_URL=libsql://你的数据库地址.turso.io
TURSO_AUTH_TOKEN=你的数据库Token

# 管理员账号密码（后台登录用）
ADMIN_USERNAME=jintianchishenme
ADMIN_PASSWORD=helloworld
JWT_SECRET=hust-map-secret-key
```

### 3. 启动本地服务（具体步骤）
1. 按下 **`Win + R`** 键打开“运行”窗口，输入 **`cmd`** 并回车，打开命令提示符黑窗口。
2. 在 cmd 中，使用 `cd` 命令进入你所在项目所在的文件夹根目录。例如（请替换为你电脑上的实际路径）：
   ```cmd
   cd C:\Users\Lenovo\Desktop\lindaCoca-map-main\lindaCoca-map-main
   ```
3. 首次运行或更新代码后，先输入以下命令安装依赖：
   ```cmd
   npm install
   ```
4. 输入以下命令启动后端服务：
   ```cmd
   node server/server.mjs
   ```
   *(如果终端显示 `✓ 数据库已有数据...` 和 `觅食地图本地服务已启动`，说明成功。)*
5. 打开浏览器，直接访问这个网址即可预览：
   **[http://127.0.0.1:3000/#home](http://127.0.0.1:3000/#home)**

> 💡 **纯前端调试模式**：如果你只想看页面样式，不跑后端，可以直接用 Live Server 打开 `index.html`。它会自动降级读取本地的 `seed.json`（但此时打分的分数只能存在浏览器缓存里，无法同步）。

## 🛠️ 三、日常维护与修改指南

### ❌ 为什么不建议直接改 `seed.json`？
现在项目已经连接了**云端数据库**。如果网站上有真实用户打分或管理员添加了菜品，你修改本地的 `seed.json` 是**无法覆盖**云端数据的（除非清空整个云端数据库重新导入）。

### ✅ 正确修改数据的方式：
打开网站 -> 右上角 **“管理员入口”** -> 输入账号密码登录。
1. **店铺管理**：增删改地点、修改坐标。
2. **菜品管理**：增删改菜品、修改价格/楼层/店铺归属。
3. **反馈审核**：处理用户提交的纠错信息。

所有的操作都会**实时保存到云端**，所有访问网页的人立刻就能看到最新数据，不用重启服务器。

### 🗺️ 关于地图坐标修改：
登录管理员后，点击地图上的 **“编辑模式”**，可以直接拖拽地图上的红点/绿点来修改地点位置，松手确认即可保存。

## 🚑 四、常见报错排查

1. **启动报错 `Unsupported type of value`**
   * 原因：数据库里有的必填字段传了 `undefined`。
   * 解决：检查是否修改了后端 `app.mjs` 的 API 路由逻辑，确保传入数据库的字段都是合法的。
2. **前端显示“本地模式”且没有分数**
   * 原因：前端请求 `/api/places` 失败或超时，自动降级读取了本地 `seed.json`。
   * 解决：检查 cmd 终端后端服务是否启动，`.env` 配置是否错误，或者尝试刷新页面。
3. **画面卡在“正在加载地图底图…”**
   * 原因：Leaflet 地图 CDN 加载失败，或网络问题。
   * 解决：强刷（Ctrl+F5），或者在右上角切换“极简 / 街道 / 卫星”底图。
4. **世界城等商场内的菜品分类混乱**
   * 原因：商场结构复杂，有时没填店铺名或楼层。
   * 解决：进入后台的“菜品管理”，把对应菜品的“店铺名称”和“楼层”填完整即可。

## 🚀 五、如何部署到线上（Zeabur）

1. 把代码推送到 GitHub 仓库（**注意：`.env` 文件千万不要传上去！**）。
2. 登录 [Zeabur](https://zeabur.com/)，新建项目，绑定该 GitHub 仓库。
3. 在 Zeabur 环境变量（Environment Variables）中，把本地 `.env` 里的所有变量填进去。
4. 部署成功后，生成免费的 `.zeabur.app` 域名，全班同学都可以访问了！
